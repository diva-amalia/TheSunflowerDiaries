# 🌻 The Sunflower Diaries

A peaceful digital garden where poems and notes can bloom.

## Features

- 🌻 Create poems
- 📝 Create notes
- 🌍 Public Explore page
- 🔍 Search poems, notes, and gardeners
- 💛 Cherish poems and notes
- 👤 Public profile
- 📱 Responsive layout
- ⚡ AJAX interactions

## Built With

- Flask
- SQLAlchemy
- Flask-Login
- HTML
- CSS
- JavaScript
